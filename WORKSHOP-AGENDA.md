# GitHub Copilot Workshop Agenda

A 55-minute, hands-on session for marketers new to GitHub. Using the scenario of designing a Microsoft Ignite speaker session, attendees will install the GitHub Copilot app, add a project, and turn Microsoft 365 context into a rough presentation deck.

## Agenda

- 0–3 min — Belinda: Welcome and introduction
- 3–8 min — Ashley: Why GitHub Copilot is valuable and how DMO uses it
- 8–10 min — Elijah: Ignite scenario and workflow overview
- 10–20 min — Download, install, and sign in
- 20–27 min — GitHub basics and app orientation
- 27–32 min — Add the demo project
- 32–42 min — Gather Teams, email, and document context with WorkIQ
- 42–48 min — Create the Ignite narrative, outline, and rough slides
- 48–51 min — Debugging and troubleshooting
- 51–55 min — Q&A and next steps
