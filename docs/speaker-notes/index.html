This page is unlinked and excluded from search indexing. The direct URL is obscurity, not authentication.

01

Projects

What it does
Connects a repository or folder so Copilot sessions use the correct files and workspace.
What to click
+ beside Projects → Add GitHub repository → e-straight/marketing-copilot-demo → Add.

02

Sessions

What it does
Keeps one task, conversation, branch, and working context together.
What to click
Open the workshop project → click New session → type the task in the composer → press Enter.

03

Canvas

What it does
Opens editable or interactive output beside the conversation, including documents, slides, spreadsheets, and browser previews.
What to click
Click the output card or Open action above the composer. Use the canvas controls to review the result while the session stays open.

04

WorkIQ

What it does
Lets Copilot use the signed-in participant's Microsoft 365 context, including calendar, email, Teams, and files.
What to click
In a session, ask the WorkIQ access-check question → click Sign in if prompted → choose the Microsoft work account → return to the session and resend.

05

Customize and installed tools

What it does
Shows installed extensions and tool connections, including whether they need authentication.
What to click
Customize in the sidebar → Installed → find WorkIQ → Sign in. For a repository-defined server: project Settings → Repository customizations → MCP servers.

06

Authentication and permissions

What it does
Connects GitHub, organization, and Microsoft 365 access to the app without sharing credentials in chat.
What to click
Sign in to GitHub → complete browser authorization → approve organization SSO if shown. For WorkIQ, use only the in-app Sign in action and the Microsoft authorization window.
