GitHub Copilot workshop

Workshop setup

  1. 1

    Download the GitHub Copilot app

    Open the official releases page and choose the installer for your computer.

    Open app downloads

    GitHub releases

    1. Open the newest release.
    2. Under Assets, choose macOS or Windows.
    3. Run the downloaded installer, then open the app.
  2. 2

    Sign in to GitHub

    Use the GitHub account approved for this workshop.

    GitHub Copilot app

    1. Click Sign in to GitHub.
    2. Complete the browser sign-in and authorization.
    3. Return to the app when your account appears in the sidebar.
  3. 3

    Add the workshop project

    Add the workshop repository so your sessions have the right files and context.

    Open workshop repository

    Projects

    1. Click + beside Projects.
    2. Choose Add GitHub repository.
    3. Select e-straight/marketing-copilot-demo, then click Add.
  4. 4

    Confirm WorkIQ access

    Start a session in the workshop project and send this access check.

    Use WorkIQ to list the titles and start times of my next three calendar events.

    If WorkIQ asks you to connect

    1. Click Sign in in the authorization prompt.
    2. Use your Microsoft work account.
    3. Return to the session and send the access check again.

Readiness check

You are ready when all four are true.

  • The GitHub Copilot app opens.
  • Your GitHub account appears in the app.
  • The workshop project appears under Projects.
  • WorkIQ returns your calendar results.
